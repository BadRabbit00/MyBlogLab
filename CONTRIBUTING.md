# Разработка

1. Создай ветку от `main`.
2. Внеси изменение и добавь тесты для изменённого поведения.
3. Выполни `nix develop . --command python -m pytest -q` и `git diff --check`.
4. При изменениях контейнера собери `nix build .#container`, загрузи образ
   `docker load --input result` и запусти `bash scripts/smoke-container.sh`.
5. В pull request опиши поведение до и после изменения и проведённые проверки.

Не добавляй токены, `.env`, содержимое `secrets/`, рабочие данные и логи.
Используй подставные значения в тестах. `.gitattributes` задаёт LF для текстовых
файлов; `.editorconfig` описывает отступы. Новые зависимости добавляются в Nix;
изменения версий должны сопровождаться обновлением `flake.lock`.
